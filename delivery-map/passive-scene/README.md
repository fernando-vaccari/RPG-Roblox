# Cópia passiva do cenário — sem scripts de projeto

[Arquivo Eldravyn-Continent-SceneryOnly.rbxlx](https://github.com/fernando-vaccari/RPG-Roblox/raw/refs/heads/codex/eldravyn-map-20261027/delivery-map/passive-scene/Eldravyn-Continent-SceneryOnly.rbxlx)

Este é um **artefato de cenário para inspeção no editor**, com somente Workspace e Lighting. Não contém Script, LocalScript, ModuleScript, Source, LinkedSource ou blobs binários. As 20.001 peças, transformações, materiais, cores, placas e iluminação foram preservados; metadados de integração permanecem no projeto/artefato original e foram excluídos desta cópia visual.

**Não há confirmação de que o Defender deixará de alertar.** O pacote anterior continua com alerta `Trojan:Script/Ulthar.A!ml`, sem causa identificada. Esta cópia não é apresentada como correção de malware ou arquivo certificado pelo antivírus. Mantenha a proteção ativa; se houver bloqueio, não libere/execute o arquivo e solicite análise à [Microsoft](https://www.microsoft.com/en-us/wdsi/filesubmission).

**Limite funcional:** Terrain nativo não estava no artefato original e também não está nesta cópia. Não há `PrepareStudio()` ou gerador incluído. É possível inspecionar a arquitetura no editor; isso não é uma versão jogável completa. O avatar pode cair fora dos pisos se entrar em Play sem terreno. O projeto original permanece preservado para continuidade.

Os [hashes](SHA256SUMS.txt) e o [manifesto](MANIFEST.json) verificam identidade/conteúdo, não inocuidade. A revisão independente confirmou igualdade de 21.330 instâncias e 223.319 propriedades, excluindo apenas atributos personalizados. Não foram executados Studio nem antivírus. Tentativa de preparar ClamAV ficou bloqueada pela indisponibilidade da base de assinaturas, conforme [relatório](../../docs/PASSIVE_SCENE_REVIEW.md).

O GitHub pode abrir `.rbxlx` como texto. Use botão direito no link → **Salvar link como…** para salvar o arquivo, mantendo o Defender ativo. Nenhuma mudança de extensão, ofuscação, carregador substituto ou novo ZIP foi usada para tentar contornar a detecção.
