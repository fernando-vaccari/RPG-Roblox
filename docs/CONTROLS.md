# Controles atuais

| Controle | Ação |
| --- | --- |
| Mouse esquerdo / ferramenta | Ataque básico; sequência de quatro golpes |
| Mouse direito / Pesado | Ataque pesado com stamina |
| F pressionado / Bloquear | Bloqueio frontal; botão móvel alterna |
| Ctrl esquerdo / Esquiva | Deslocamento e invulnerabilidade curta, com cooldown |
| Shift esquerdo / Correr | Corrida enquanto stamina permite; botão móvel alterna |
| Z X C V | Quatro slots da classe, definidos em AbilityConfig.Slots |
| Q / Pulso | Técnica básica do cajado |
| K / Habilidades | Menu da classe, aprendizado e uso das 24 habilidades |
| I / Inventário | Equipar/desequipar, ver materiais e usar poções |
| J / Missões | Diário de objetivos |
| E / prompt de toque | Conversar, interagir e abrir baús |

Aprendizado requer contexto de mestre de armas/arcanista/mago próximo. Venda requer mercador próximo. Menu aberto não concede permissões: servidor revalida. Em celular, habilidades são acionadas por botões no menu; mira de habilidades sem ponteiro usa direção do personagem.

Estes controles foram escritos e compilados; resposta a teclado/toque e layout em resoluções reais permanecem NÃO TESTADOS.

## Linhagens e classes

- **L** / **Linhagem**: raça, traços, evolução, desafios de classes, fragmentos e fusões.
- **R** / botão “Usar habilidade racial”: ação própria da raça com custo/cooldown no servidor.
- **Z/X/C/V**: slots da classe avançada quando selecionada; técnicas da classe-base continuam no menu de habilidades.
- No menu de linhagem há link para habilidades, inclusive no celular. Selecionar uma classe desbloqueada não entrega armas grátis.

Os pacotes Robux não abrem janelas quando ProductId é zero. A tentativa gratuita racial após 24h não depende da compra.

## Navegação e qualidade 0.5.0

- **M / Menu**: navegação principal, atlas, inventário, missões, linhagem, habilidades e configurações.
- **Configurações**: LOW/MEDIUM/HIGH de apresentação, som e movimento reduzido. Não muda valores autoritativos ou a quantidade já gerada de árvores.
- **Áreas de chefes**: saia do vermelho; em ataques de anel, o disco verde central é seguro. O aviso precede a aplicação do dano.
- **Admin Tester**: só aparece com opt-in no Studio sem persistência. Produz relatório de benefício, sem alterar perfil real.

Projéteis selecionados exigem tempo de viagem; partículas/efeitos gráficos não autorizam dano. Voz/som dependem de assets próprios publicados; IDs permanecem vazios quando não configurados.
