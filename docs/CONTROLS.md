# Eldravyn — controles atuais

| Ação | PC | Celular |
| --- | --- | --- |
| Movimento/salto | WASD / Espaço | Controles nativos |
| Interação | E | Prompt |
| Ataque/pesado | Clique esquerdo/direito | Ataque/Pesado |
| Bloqueio/parry | Segure F; pressione perto do golpe para aparar | Segure Bloquear; toque no momento do golpe para aparar |
| Esquiva/corrida | Ctrl/Shift esquerdos | Esquiva/Correr |
| Quatro habilidades | Z/X/C/V | Hotbar de habilidades |
| Racial/pulso | R/Q | Racial/Pulso |
| Inventário/missões | I/J | Menu/atalhos |
| Habilidades/linhagem/menu | K/L/M | Menu |

Mira touch usa o centro da câmera. Inventário próprio equipa a Tool automaticamente; hotbar nativa duplicada é ocultada. NPCs exigem proximidade/conversa; preços, dano e progresso são verificados no servidor. Teclas de texto não disparam ações enquanto o campo está processando entrada.

Menus Personagem, Tutorial e Expedições estão no menu principal. A interface mostra carga/morte e avisa ausência de salvamento na prévia. Layout/gestos reais aguardam TESTES_STUDIO.md.
